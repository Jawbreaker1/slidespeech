# Shared Presentation Fonts

Unmodified full TrueType assets from Adobe's official repositories, licensed
under SIL OFL 1.1. The adjacent license files must be redistributed with them.
These are shared by server measurement and the bundled browser stylesheet;
there is no OS-font lookup, network fetch at runtime or subset substitution.

Full fonts include characters missing from the previous Latin-only subsets,
including scientific subscripts. This does not establish support for every
script. Unsupported glyphs fail as an asset limitation, without asking the
author to alter the language. Native PowerPoint availability/embedding remains
separate export acceptance work.
