# SlideSpeech Wordmark

These vector assets reproduce the existing Studio header wordmark: Avenir Next
Bold for `slide` and the terminal dot, Regular for `speech`, with the same relative
letter spacing. Glyph outlines make the image independent of installed fonts;
no font file, script or external resource is embedded.

- `slidespeech.svg` uses the Studio ink and terracotta accent on light surfaces.
- `slidespeech-dark.svg` uses light ink and a brighter accent on dark surfaces.

The repository README selects the appropriate asset through a `picture` element.
If the product wordmark changes, update these assets with it rather than designing
a separate documentation identity.
